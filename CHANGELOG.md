# Журнал змін — «Рух пального»

> Що змінилось для користувачів і що треба знати при деплої. Новий запис — у «Не випущено»; при викладці розділ переноситься під версію з датою.
> Позначки: **Додано** · **Змінено** · **Виправлено** · **Деплой** (міграції, нові змінні `.env`, залежності).

## [Не випущено]
### Додано
- Сторінка «Карти»: кнопка «Оновити карти Petroline» — підтягує картки з нового API Petroline (лише читання): номер на картці, ID, статус, назву водія/авто.
- Картка має «Номер на картці» (`ext_number`) і «ID у провайдера» (`external_id`); для Petroline ключем зв'язку з транзакціями лишається «Ідентифікатор».
- Сторінка «Карти»: швидкий перемикач «Всі / Активні / Неактивні» (неактивні — усі, крім статусу «Активна»).
- Сторінка «Транзакції»: колонка «Ідентифікатор» (за замовчуванням прихована), у колонці «Картка» — номер на картці; пошук за обома номерами; те саме в експорті CSV.
### Виправлено
- Сторінка «Транзакції»: кнопка «Синхронізувати» знову зелена і стоїть першою, перед «Колонки ▾»; розмір збігається з іншими кнопками.
### Деплой
- Міграція `0004_card_ext_number_external_id` (додає два порожні поля, не деструктивна).
- `.env`: для нового API Petroline потрібен звичайний (не SHA256) пароль — `PETROLINE_V2_LOGIN`/`PETROLINE_V2_PASSWORD` або `PETROLINE_LOGIN`/`PETROLINE_PASSWORD`. Змінна `UPG_TOKEN` більше не використовується.
