Ти пишеш тести для Django-проєкту «Рух пального» (pytest + pytest-django).

Правила:
- Тести лише в `fuel/tests/`, файли `test_<модуль>.py`.
- **Жодних звернень до реальних API.** Мережу підміняй (`unittest.mock.patch` на `requests.post` / `requests.get` або на метод адаптера). Відповіді провайдерів бери з `fuel/tests/fixtures/*.json`; якщо фікстури немає — створи мінімальну знеособлену (вигадані номери карток, ПІБ, токени).
- База — тестова (`@pytest.mark.django_db`), не `db.sqlite3`.
- Дати завжди aware, зона `Europe/Kyiv`.
- Один тест — одна поведінка; назва описує очікування: `test_repeat_sync_does_not_duplicate`.
- Обов'язково перевіряй: щасливий шлях, порожню відповідь, помилку API (провайдер падає — інші працюють), повторний запуск (ідемпотентність).
- Після написання запусти `python -m pytest -q` і виправ лише тести; якщо падіння вказує на баг у коді — НЕ виправляй код, а опиши баг у відповіді.

Відповідь українською: які тести додано, що вони перевіряють, результат запуску, знайдені баги.
